はじめての CTF

        
CTF（Capture The Flag）は、セキュリティの知識を使って隠された「フラグ」を探し出す競技です。答えは flag{...} のような文字列で、見つけて提出すると得点になります。

        
基本の進め方

        
    
        
    ジャンル別の最初の一歩
    
        
    
        
    
        
    用語集
    
        
        
    
        
    ルールとマナー
    
        
      
      
      

      
      
      
      
        
      QUICK ACCESS // FAVORITES
      
        
      お気に入り
      
        
      
      
      

      
      
        
      迷ったら診断
      
        
      問題に出てきた文字列を貼るか、ファイルを入れてください。正体を推測して、次にやることと使うツールを提案します。
      
        
      
          
          
          
      
            試しに:
            
            
            
            
            
          
      
        
      
        
        
      
      
      

      
      
      
        
      エンコード / デコード
      
        
      変換を順番につなげて、読めないデータを元に戻します（CyberChef と同じ考え方）。各段階の結果がその場で見え、次に試す変換を自動で提案します。
      
        
      
          
      
            
            
      
              
              
              
            
      
          
      
          
          
      
        
      

        
      
          
      
            
      全自動で試す（Magic）
      
            
          
      
          
      Base64 / Base32 / Base58 / Base85 / Hex / 2進・10進 / URL / HTML / Unicode / モールス / uudecode / gzip・zlib を重ねて試し、読める結果やフラグが出たものを上位に表示します。「適用」で下のレシピに手順が入ります。
      
          
      
        
      

        
      
          
      
            
      変換を探す
      
            
            
      
          
      
          
      
            
      
              
      
                
      レシピ（上から順に実行）
      
                
      
                  
                  
                  
                  
                
      
              
      
              
      
              
      
              
      
            
      
          
      
        
      

        
      
          
      
            
            
      
              
              
              
              
            
      
          
      
          
          
      
          
      
          
      
          
      
        
      
      
      

      
      
      
        
      基数変換
      
        
      
          
          
          
      
          
      
        
      
        
      
          
          
          
      
        
      
      
      

      
      
      
        
      古典暗号
      
        
      
          
          
        
      
        
      
          
          
          
          
          
          
        
      
        
      
          
      
            
      
              
      シーザー暗号（全シフト）
      
              
      いちばん英文らしい行（とフラグを含む行）を強調表示します。
      
              
      
            
      
            
      
              
      ROT47 / Atbash / 反転
      
              
      
            
      
          
      
          
      
            
      
              
      鍵がわからない：自動解読
      
              
      一致指数（IoC）で鍵の長さを推定し、各列を頻度分析で解きます。英文で 20 文字以上（できれば 100 文字以上）あると精度が上がります。
      
              
              
      
              
      
            
      
            
      
              
      鍵がわかる：暗号化 / 復号
      
              
      
                
                
                
              
      
              
      
            
      
          
      
          
      
            
      
              
      Affine 暗号（全 312 通りの鍵を総当たり）
      
              
      E(x) = (a·x + b) mod 26。英文らしい順に上位 10 件を表示します。
      
              
      
            
      
          
      
          
      
            
      
              
      Rail Fence 暗号（段数 2〜12 を総当たり）
      
              
      
            
      
          
      
          
      
            
      
              
      単一換字式：手動解読表
      
              
      上段の暗号文字に対応する平文字を入力すると、すぐに反映されます（未割り当ては「_」）。まず「頻度順で仮割り当て」を押してから直していくと早いです。
      
              
      
                
                
              
      
              
      
              
      
            
      
          
      
          
      
            
      
              
      文字の出現頻度
      
              
      明るい棒: 入力の頻度 / 灰色: 英語の一般的な頻度。形が英語に近ければ転置式か単一換字式、平らならば多表式（Vigenère など）の可能性があります。
      
              
      
              
      
            
      
          
      
        
      
      
      

      
      
      
        
      XOR
      
        
      
          
      
            
            
          
      
          
          
      
          
      
        
      
        
      
          
          
          
          
        
      
        
      
          
      
            
      
              
      
                
                
                
              
      
              
      
            
      
          
      
          
      
            
      
              
      1バイト鍵の総当たり（上位 20 件）
      
              
      
            
      
          
      
          
      
            
      
              
      繰り返し鍵 XOR の自動解読
      
              
      ハミング距離で鍵の長さ（2〜40）を推定し、各列を1バイト総当たりで解きます。データが長いほど正確です。
      
              
              
      
            
      
          
      
          
      
            
      
              
      既知平文（crib）から鍵を推定
      
              
      平文に含まれるとわかっている文字列（例: flag{）とデータを XOR して、その位置の鍵を求めます。鍵が読める文字になった位置を一覧表示します。
      
              
      
                
              
      
              
      
            
      
          
      
        
      
      
      

      
      
      
        
      RSA
      
        
      
          
      わかっている値だけを入力してください（10進または 0x 付き16進）。p・q・d のどれかがあれば復号し、無い場合は「n が素数」「小さい素因数」「Wiener 攻撃（d が小さい）」「Fermat 法（p と q が近い）」「小さい e」を順に試します。
      
          
      
            
      
            
      
            
      
            
      
            
      
            
      
          
      
          
      
            
            
          
      
          
      
          
        
          
        
        
        
      
        

      
      
        
        
        ファイル解析
        
        
        
        
          
        
            
        概要
        
            
        
            
        
          
        
          
        
            
        エントロピー分布
        
            
        8 に近いほど乱雑（圧縮・暗号化データ）、低いほど規則的です。一部だけ高い場所には別のデータが埋め込まれていることがあります。
        
            
        
          
        
          
        
            
        暗号の手がかり
        
            
        
          
        
          
        
            
        埋め込まれたファイルの署名
        
            
        
          
        
          
        
            
        PNG チャンク
        
            
        
            
        
          
        
          
        
            
        文字列
        
            
        
              
              
              
              
            
        
            
        
            
        
          
        
          
        
            
        
              
        16進ダンプ
        
              
        
                
                
                
              
        
            
        
            
        
          
        
        
        
      
        

      
      
        
        
        ハッシュ
        
        
        
          
          
          
        
          
        ファイルのハッシュは「ファイル解析」で計算できます。
        
        
        
        
        
          
          
          
        
        
        
      
        

      
      
        
        
        JWT デコード
        
        
        
          
          
          
        中身を表示するだけで、署名の検証は行いません。
        
          
        
          
        
        
        
      
        

      
      
        
        
        フラグ検索
        
        
        
          
          
          
        
            
        
              
              
            
        
          
        
          
        
            正規表現を変更する
            
          
        
          
        そのまま・Base64/32・Hex・2進/10進・URL・HTML・Unicode・ROT47・Atbash・反転・シーザー全シフトを試します。文字をずらす系の変換は、接頭辞が一致したものだけ表示します。ここで設定した接頭辞は Magic やファイル解析でも使われます。
        
          
        
          
        
        
        
      
        

      
      
        
        
        ネットワーク・時刻
        
        
        
          
        IPv4 / CIDR 計算
        
          
          
        
          
        
        
        
        
        
          
        
            
        タイムスタンプ変換
        
            
          
        
          
          
        UNIX 時間（秒・ミリ秒・マイクロ秒）、Windows FILETIME、日時文字列に対応しています。数値は桁数から考えられる解釈をすべて表示します。
        
          
        
          
        
        
        
      
        

      
      
        
        
        画像解析
        
        
        
        
          
        
          
        
            
            
            
            
          
        
          
        
            
        
              
        
                
        各チャンネル（R / G / B / A）の各ビットを白黒で表示します。下位ビット（0〜1）に文字や模様が浮かべば、何かが隠されています。一覧のサムネイルをクリックすると大きく表示します。
        
                
        
              
        
              
        
                
        
                  
        元の画像
        
                  
        
                    
                    
                  
        
                
        
                
        
              
        
            
        
            
        
              
        
                
        自動スキャン
        
                
        よく使われる埋め込み方（チャンネルの組み合わせ・ビット・読む向き）を順に試し、読める文字・フラグ・ファイルの署名が出たものを表示します。
        
                
                
        
              
        
              
        
                
        条件を指定して取り出す
        
                
        
                  
        
                  
        
                  
        
                  
        
                
        
                
        
                
        
                
        
              
        
            
        
            
        
              
        
                
        撮影日時・機種・位置情報・コメントなど、画像に埋め込まれた情報です。OSINT の手がかりや、フラグが直接書かれていることもあります。
        
                
                
        
              
        
            
        
            
        
              
        
                
        画像の中の QR コードを読み取ります。読めないときは、白黒を反転したもの・各ビットプレーンでも試します。
        
                
                
        
              
        
            
        
          
        
        
        
      
        

      
      
        
        
        バイナリ解析（逆アセンブル）
        
        
        実行ファイル（ELF / PE）の中身を、関数の一覧・疑似コード・逆アセンブル・分岐のグラフで読みます。Ghidra でやる「main を探す → 文字列から判定の場所を見つける → 比べている値を読む」を、ブラウザだけで行えます。ファイルは外部へ送りません。
        
        
        
        
          機械語（シェルコード）を直接貼って逆アセンブルする
          
        
            
            
            
          
        
          
        
        
        
        
        
        
          
        
            
        
            
        
            
        
            
        
          
        
          
        
            
        
              
        
                
                
              
        
              
        
                
        
                  
                  
        
                
        
                
        
                  
                  
                  
        
                
        
              
        
            
        
            
        
              
        
                
                
                
                
                  
                  
                
              
        
              
        
              
        
                
                
                
                
              
        
              
        
                
        
                  
        レジスタの中身を追いかけて組み立てた簡易の疑似コードです（型や構造体は推測しません）。怪しいところは逆アセンブルで確かめてください。行をクリックすると、その命令へ移動します。
        
                  
        
                
        
                
        
                
        
                  
        
                    
                    
                    ━ 条件が成り立つ　━ 成り立たない　━ そのまま進む　ブロックをクリックで逆アセンブルへ
                  
        
                  
        
                
        
                
        
                  
        
                    
                    
                    
                  
        
                  
        逆アセンブルや疑似コードに出てくる配列・データのアドレスを入れると、中身を表示します。比較に使われている配列を取り出して、XOR などのツールへ送れます。
        
                  
        
                  
        
                    
                    
                    
                    
                    
                  
        
                
        
              
        
            
        
          
        
        
        
      
        
      
        
        
        位置特定アシスタント
        
        
        画像から撮影場所の手がかりを集め、地図で調べるところまでを手伝います。画像は外部へ送らず、すべてこの端末の中で処理します。
        
        
        ※ 大会の問題として出された画像だけに使ってください。実在する人の写真から居場所を割り出すことは、プライバシーの侵害になります。
        
        
        
        
          
        
            
        ① EXIF の位置情報
        
            
        
            
        
          
        
          
        
            
        
              
        ② 写っている文字を読み取る（OCR）
        
              
        
                
                
                
                
              
        
            
        
            
        写真の中の文字向けの OCR（PaddleOCR）を端末の中で動かします。看板の部分をドラッグで囲むと、その範囲だけを拡大して読むので、遠くの小さな文字に強くなります。初回だけ読み取り用のデータ（約 34MB）をダウンロードし、以後はオフラインでも使えます。
        
            
        
              
              
        
              
        
            
        
            
        
            
        
              
              
            
        
            
            
        
              スマホの文字認識を使う方法（読み取りに失敗したとき）
              
          
                
        • iPhone：写真アプリで画像を開き、右下の「テキスト認識表示」ボタン（または文字を長押し）→ 文字を選んでコピー
          • 
                
        • Android：Google フォトで画像を開き「レンズ」→「テキスト」→ コピー
          • 
                
        • コピーした文字を、上の「クリップボードから貼り付け」で取り込むと、手がかりの抽出がそのまま使えます
          • 
              
        
            
        
          
        
          
        
            
        手がかりと地図検索
        
            
        
            
        
            
        
              
              Google マップ
              OpenStreetMap
            
        
          
        
          
        
            
        ④ 画像の逆引き検索
        
            
        同じ写真や似た景色が載ったページを探します。「画像をコピー」してから各サービスを開き、貼り付け（Ctrl+V / ⌘V）またはアップロードしてください。※ 画像がそのサービスに送られるので、大会ルールで外部サービスが使えるか確認してから使いましょう。
        
            
        
              
              Google レンズ
              Bing ビジュアル検索

        音声解析
        
        
        
        
          
        
            
        
            
            
        
              
        
              
        
              
        
              
        
              
            
        
            
        スペクトログラムは横が時間・縦が周波数です。音に文字や絵が隠されていると、ここに浮かび上がります。
        
            
        
          
        
        
        
      
        

      
      
        
        
        pcap 解析
        
        
        
        
          
        
          
        
          
        
            
            
            
            
          
        
          
        
            
        
              
        
                
                
        
                
        
              
        
            
        
            
        
              
        
                
        
              
        
              
        
                
        
                  
        
                  
        
                    
                    
                    
                  
        
                
        
                
        ■ クライアント → サーバー　■ サーバー → クライアント
        
                
        
              
        
            
        
            
        
              
        
            
        
            
        
              
        
                
        問い合わせたドメイン名の一覧です。サブドメインに Base64 などでデータを載せて外へ送る手口（DNS トンネリング）にも注意しましょう。
        
                
        
              
        
            
        
          
        
        
        
      
        

      
      
        
        
        ログ解析
        
        
        
          
        
            
            
        
          
        
          
        
        
        
        
          
        
          
        
            
        時間ごとの件数
        
            
        急に増えた時間帯（警告色）は、攻撃や異常が起きた可能性があります。棒をクリックすると、その時間帯の行を表示します。
        
            
        
            
        
          
        
          
        
            
        アクセスの多い IP
        
            
        失敗の多い IP
        
            
        ステータスコード
        
            
        よくアクセスされたパス
        
          
        
          
        
            
        該当する行
        
            
        
            
        
          
        
        
        
      
        

      
      
        
        
        AI 入力チェック
        
        
        AI（LLM）に読ませる文章・Web ページ・Markdown に、人には見えにくい指示や情報の持ち出し経路が紛れ込んでいないかを調べ、安全な形に整えます。
        
        
        
          
        
            
            
        
          
        
          
        
        
        
        
          
        
            
            
            
            
            
          
        
          
        
            
        
            
        
              
        
                
        
                
        
                
        見えない文字を記号で表示
        
                
        
                
        
              
        
            
        
            
        
            
        
              
        
                
        指示の乗っ取りによく使われる表現を、日本語・英語で探します。当てはまっても攻撃とは限りませんが、AI に渡す前に確認が必要です。
        
                
        
                
        
              
        
            
        
            
        
              
        
                
        
                  
                  
                  
                  
                  
                
        
                
        無害化した文章
        
                
        
                
        変更点
        
                
        
                
        無害化は被害を減らす手段の1つで、これだけで安全になるわけではありません。権限の最小化や人による確認と組み合わせましょう（チートシートの「AI セキュリティ」を参照）。
        
              
        
            
        
          
        
        
        
      
        

      
      
        
        
        数論計算機
        
        
        
          
          
          
          
        
        
        
        
          
        
            
        
              
              
        
              
        小さい素因数は割り算で、大きめの素因数は Pollard の ρ 法で探します（最大 4 秒）。RSA の n のように大きな素数2つの積は、ここでは分解できないのが普通です。
        
              
        
            
        
          
        
          
        
            
        
              
        
              
        入力すると、GCD・LCM・a⁻¹ mod n・aᵇ mod n・拡張ユークリッドの係数をまとめて計算します。
        
              
        
              
        
            
        
          
        
          
        
            
        
              
              
              
        x ≡ 余り (mod 法) をすべて満たす x を求めます。法が互いに素でなくても、矛盾が無ければ解けます。
        
              
        
              
        
            
        
          
        
          
        
            
        
              
        
              
        
              
        
            
        
          
        
        
        
      
        

      
      
        
        
        バイナリビューア
        
        
        
          
        
            
            
          
        
          
          
        
          
        
        
        
        
        
          
        10進または 0x 付きの16進
        
          
        
        
        
        
        
          
          
          
        
          
        
        
        
      
        

      
      
        
        
        文字化け修復
        
        
        
          
        
            
            
          
        
          
          
        「本当は UTF-8 なのに Shift_JIS として読んだ」のような取り違えを逆にたどり、読みやすい順に候補を出します。化けた時点で失われた文字は「?」になります。

        フォーム解析
        
        
        問題の HTML（入力フォーム）を貼り付けると、送信先・入力欄・隠れた手がかりを一覧にし、送信リクエストの組み立て・curl / fetch の生成・弱点の当たりを示します。解析はこのブラウザの中だけで行い、どこにも送信しません。
        
        
        
          
          
          
          
          
        
            
            
          
        
        
        
        
        
      
        

      
        
        
        難読化 JS デコード
        
        
        aaencode（顔文字）・JSFuck・Packer など、eval / Function で文字列を実行する形の難読化 JavaScript から、実行せずに中身のコードを取り出します。
        
        
        
          
          
          
        
          
        
            
            
            
          
        
          
        しくみ：通信も画面操作もできない隔離フレーム（sandbox・CSP で外部通信禁止）の中で、eval / Function / setTimeout(文字列) / document.write を「受け取った文字列を記録するだけ」の関数に差し替えてから読み込みます。最後の「実行」の直前で止めるので、中身のコードは動きません。多段の難読化は「さらにデコード」で 1 段ずつ剥がします。
        
        
        
        
        
      
        

      
        
        
        JS 実行サンドボックス
        
        
        問題の JavaScript の一部や、逆算するために自分で書いたコードをその場で動かします。console.log・alert・最後の式の値が結果に出ます。スマホでも使える「開発者ツールのコンソール」の代わりです。
        
        
        
          
        
            
            
          
        
          
          
          
          
          
        
            
            
          
        
          
        隔離フレームの中の別スレッドで実行します。外部との通信・ポータルの画面や保存データへのアクセスはできず、時間制限を超えると強制停止するので、無限ループでも固まりません。$（jQuery）と document は最小限のまねで、フォームの送信・クリックの処理は「すぐ送信された」として実行されます。
        
        
        
        
        
      
        

      
        
        
        難解言語ランナー
        
        
        Whitespace（スペース・タブ・改行だけで書く言語）・Brainfuck・Ook! のプログラムを実行します。普通のソースコードの空白に Whitespace のプログラムが隠れている問題によく使います。
        
        
        
          
        
            
            
            
          
        
          
          
          
        
          
          
          
        
            
            
            
          
        
          
        Whitespace は空白・タブがひとつ欠けても動きません。Web ページの表示やチャットからコピーすると行末の空白やタブが消えやすいので、問題のファイルをダウンロードして「ファイルを開く」で読み込むのが確実です。上限ステップ数で止まるので、無限ループでも固まりません。
