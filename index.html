CTF Portal

自動解析（Magic）

            
          

          
Base64 / Base32 / Base58 / Base85 / Hex / 2進・10進 / URL / HTML / Unicode / モールス / gzip・zlib を重ねて試し、読める結果やフラグが出たものを上位に表示します。最後にシーザー全シフト・ROT47・反転でフラグが出るかも確認します。

レシピ（変換を順番につなげる）

          

            
            
            
            
          

          
    
        
    

        
    
          
    
            
            
    
              
              
              
              
            
    
          
    
          
          
    
          
    
        
    
      
    

      
      
    
        
    基数変換
    
        
    
          
          
          
    
          
    
        
    
        
    
          
          
          
    
        
    
      
    

      
      
    
        
    古典暗号
    
        
    
          
          
        
    
        
    
          
          
          
          
          
          
        
    
        
    
          
    
            
    
              
    シーザー暗号（全シフト）
    
              
    英文らしさのスコアが高い上位3件を強調表示します。
    
              
    
            
    
            
    
              
    ROT47 / Atbash / 反転
    
              
    
            
    
          
    
          
    
            
    
              
    鍵がわからない：自動解読
    
              
    一致指数（IoC）で鍵の長さを推定し、各列を頻度分析で解きます。英文で 20 文字以上（できれば 100 文字以上）あると精度が上がります。
    
              
              
    
              
    
            
    
            
    
              
    鍵がわかる：暗号化 / 復号
    
              
    
                
                
                
              
    
              
    
            
    
          
    
          
    
            
    
              
    Affine 暗号（全 312 通りの鍵を総当たり）
    
              
    E(x) = (a·x + b) mod 26。英文らしい順に上位 10 件を表示します。
    
              
    
            
    
          
    
          
    
            
    
              
    Rail Fence 暗号（段数 2〜12 を総当たり）
    
              
    
            
    
          
    
          
    
            
    
              
    単一換字式：手動解読表
    
              
    上段の暗号文字に対応する平文字を入力すると、すぐに反映されます（未割り当ては「_」）。まず「頻度順で仮割り当て」を押してから直していくと早いです。
    
              
    
                
                
              
    
              
    
              
    
            
    
          
    
          
    
            
    
              
    文字の出現頻度
    
              
    明るい棒: 入力の頻度 / 灰色: 英語の一般的な頻度。形が英語に近ければ転置式か単一換字式、平らならば多表式（Vigenère など）の可能性があります。
    
              
    
              
    
            
    
          
    
        
    
      
    

      
      
    
        
    XOR
    
        
    
          
    
            
            
          
    
          
          
    
          
    
        
    
        
    
          
          
          
          
        
    
        
    
          
    
            
    
              
    
                
                
                
              
    
              
    
            
    
          
    
          
    
            
    
              
    1バイト鍵の総当たり（上位 20 件）
    
              
    
            
    
          
    
          
    
            
    
              
    繰り返し鍵 XOR の自動解読
    
              
    ハミング距離で鍵の長さ（2〜40）を推定し、各列を1バイト総当たりで解きます。データが長いほど正確です。
    
              
              
    
            
    
          
    
          
    
            
    
              
    既知平文（crib）から鍵を推定
    
              
    平文に含まれるとわかっている文字列（例: flag{）とデータを XOR して、その位置の鍵を求めます。鍵が読める文字になった位置を一覧表示します。
    
              
    
                
              
    
              
    
            
    
          
    
        
    
      
    

      
      
    
        
    RSA
    
        
    
          
    わかっている値だけを入力してください（10進または 0x 付き16進）。p・q・d のどれかがあれば復号し、無い場合は「n が素数」「小さい素因数」「Wiener 攻撃（d が小さい）」「Fermat 法（p と q が近い）」「小さい e」を順に試します。
    
          
    
            
    
            
    
            
    
            
    
            
    
            
    
          
    
          
    
            
            
          
    
          
    
          
      
          
      
        
      
      
      

      
      
      
        
      ファイル解析
      
        
        
      
          
      
            
      概要
      
            
      
            
      
          
      
          
      
            
      エントロピー分布
      
            
      8 に近いほど乱雑（圧縮・暗号化データ）、低いほど規則的です。一部だけ高い場所には別のデータが埋め込まれていることがあります。
      
            
      
          
      
          
      
            
      埋め込まれたファイルの署名
      
            
      
          
      
          
      
            
      PNG チャンク
      
            
      
            
      
          
      
          
      
            
      文字列

      ハッシュ

      JWT デコード

      フラグ検索
      
        
      
          
          
          
      
            
      
              
              
            
      
          
      
          
      
            正規表現を変更する
            
          
      
          
      そのまま・Base64/32・Hex・2進/10進・URL・HTML・Unicode・ROT47・Atbash・反転・シーザー全シフトを試します。文字をずらす系の変換は、接頭辞が一致したものだけ表示します。ここで設定した接頭辞は Magic やファイル解析でも使われます。
